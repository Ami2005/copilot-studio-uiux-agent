# 상품카드 리서치 보고서 스킬

## 입력
- 리서치명 (필수)
- 세부 요건, 산출물 형식 (선택: 주어지면 그 조건 안에서 작성)
- 수정 요청 시: 기준이 되는 최신 PPT와 변경 사항

## 1. 자료 확인과 최신본 선택
1. SharePoint 리서치 정보 영역에서 리서치명과 관련된 자료를 확인한다.
2. 같은 자료가 여러 개면 수정일 또는 명시된 버전을 기준으로 최신본을 사용한다.
3. 경쟁사명, 화면 또는 출처, 확인 가능한 상품카드 요소를 정리한다.
4. Aside 자료의 이미지 중 근거로 쓸 수 있는 이미지를 선별해 해당 경쟁사·화면·분석 항목과 연결한다.
5. 경쟁사의 최근 참조 이미지도 보고서에 표시한다.

## 2. 상품카드 요소 비교
아래 10개 요소를 경쟁사별로 비교한다.

| 요소 |
|---|
| 상품 이미지 |
| 상품명 |
| 가격 및 할인율 |
| 단위가격 |
| 배지 |
| 배송 정보 |
| 별점 및 리뷰 |
| 장바구니 버튼 |
| 찜 |
| 품절 표시 |

- 경쟁사별 제공 여부를 **O·X**로 표시한다.
- 요소별 우선순위를 **상·중·하**로 판단하고, 판단 근거를 자료와 연결한다.
- 자료에서 확인되지 않으면 **"확인 불가"**로 표시한다.

## 3. PPT 구성
1. **표지와 요약**
2. **경쟁사별 특징**
3. **구성 요소 비교표와 요소별 우선순위** (O·X, 상·중·하, 근거)
4. **경쟁사별 강점·약점**: 경쟁사마다 1장, 차별점·공통 패턴·강점·약점
5. **인사이트**: 1장
6. **제안**: 상품카드 UI A안과 B안, 두 안의 차별점과 기대효과 비교 1장

산출물 형식이 지정되어 있으면 그 형식에 맞춘다.

## 4. 제작 규칙
- 코드 인터프리터로 **.pptx** 파일을 생성한다.
- 모든 텍스트, 표, 도형, 캡션은 PowerPoint에서 수정 가능한 요소로 만든다.
- Aside 이미지는 관련 슬라이드에 배치하고, 무엇을 보여 주는 근거인지 짧은 캡션을 붙인다.
- 이미지 비율을 유지하고, 과도하게 자르거나 늘리지 않는다.
- 이미지가 없거나 읽을 수 없으면 임의 이미지를 만들지 않고 해당 위치에 **"이미지 확인 불가"**로 표시한다.

## 5. 파일명과 버전
- 형식: `UIUX Research_리서치명_yyyymmdd_v버전.pptx`
- 같은 프로젝트 보고서가 없으면 **v0.1**, 있으면 최신 버전에서 **0.1**을 올린다. v0.9 다음은 **v1.0**.
- 수정 요청도 최신 PPT를 기준으로 변경 사항을 반영해 새 버전으로 만든다.
- 기존 파일을 덮어쓰지 않는다.

## 6. 자료 처리 예외
- 출처가 열리지 않거나 최신 여부를 판단할 수 없으면 해당 항목을 **"확인 불가"**로 표시한다.
- 자료 간 내용이 충돌하면 양쪽 근거를 나란히 제시하고 최신 날짜를 우선한다. 최종 판단이 어려우면 작업을 멈추고 사용자 확인이 필요하다고 에이전트에 알린다.

## 출력
- 생성된 .pptx 파일과 파일명만 반환한다. 보고서 내용 미리보기는 출력하지 않는다.
