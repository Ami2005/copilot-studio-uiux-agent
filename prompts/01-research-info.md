# ① 리서치 정보 작성 프롬프트

Aside(또는 Claude 프로젝트)에서 경쟁사 PLP 상품카드를 리서치해 Word 파일로 저장할 때 사용합니다.
`< >` 부분을 바꿔서 사용하세요.

```text
<경쟁사> 사이트에서 <상품> 목록 페이지의 상품카드를 UIUX 관점으로 리서치해줘.
상품카드에 어떤 요소가 있는지, 어떤 요소를 강조하는지, 레이아웃은 어떤지 정리하고
이벤트·혜택·할인 표현과 <상품> 구매 기준 관점의 인사이트도 알려줘.
PC 웹 화면 기준으로 보고, 결과는 워드 파일로 만들어줘.

파일명은 <YYYYMMDD>_UIUX 리서치_상품카드_<경쟁사>_<상품>_v<버전>.docx 로 해줘.
같은 경쟁사·상품 리서치가 없으면 v0.1, 있으면 최신 버전에서 0.1 올려줘.
기존 파일은 덮어쓰지 말고 새 버전으로 만들어서 아래 SharePoint 폴더에 올려줘.
<SharePoint '리서치 정보' 폴더 링크>
```

## 예시

```text
쿠팡 사이트에서 생수 목록 페이지의 상품카드를 UIUX 관점으로 리서치해줘.

파일명은 <YYYYMMDD>_UIUX 리서치_상품카드_쿠팡_생수_v<버전>.docx 로 해줘.
같은 경쟁사·상품 리서치가 없으면 v0.1, 있으면 최신 버전에서 0.1 올려줘.
```

> TIP: 이미 리서치한 자료로만 작업하게 하려면 `리서치 정보 폴더 안의 정보로만 작성해줘`를 덧붙이세요.
